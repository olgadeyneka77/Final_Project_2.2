# Final Project 2: Subscription Revenue & User Retention Analytics

## 🎯 Project Overview
This project was developed as the final assignment for the Data Analytics course at GoIT. The main objective was to build an interactive Business Intelligence dashboard designed for (imaginary) Product Managers to track revenue dynamics and perform a high-level analysis of the factors influencing subscription earnings.

## 📊 Business Value & Key Questions Answered
A dashboard shouldn't just be a collection of pretty charts; it must provide immediate answers to critical business questions. This tool helps stakeholders track:
- **Revenue Dynamics:** Monitoring Monthly Recurring Revenue (MRR) growth and breakdown.
- **Expansion vs. Contraction MRR:** Identifying growth drivers versus revenue loss.
- **Customer Value & Retention:** Tracking Average Revenue Per Paying User (ARPPU), Churn Rate, Lifetime (LT), and Customer Lifetime Value (LTV).
- **Drill-Down Capabilities:** Investigating shifts in metrics across different dimensions such as time, language, and game variations.

## 🛠️ Tech Stack & Methodology
The project was executed in a rigorous two-stage workflow:
1. **Data Extraction & Transformation (SQL & DBeaver):** Extracted, cleaned, and structured raw data from a PostgreSQL database (schema `project`).
2. **Business Intelligence (Tableau Public):** Transformed raw figures into an actionable, user-centric interactive dashboard.
